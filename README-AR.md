# تمرينك — موقع رياضي عربي قابل للتثبيت

## الموجود داخل المشروع
- صفحات مستقلة: الرئيسية، الملف الرياضي، مكتبة التمارين، الخطة الأسبوعية، السعرات والوجبات، وضعية الظهر، التقدم، مدرب الذكاء الاصطناعي، والإعدادات.
- **200 تمرين** موزعة على 10 أقسام، مع العضلات والمعدات والمستوى والمجموعات والتكرارات والراحة وطريقة التنفيذ والتنفس والأخطاء والبدائل وتنبيهات السلامة.
- حاسبة سعرات تقديرية، سجل وجبات تقريبي، **تقدير وجبة بالذكاء الاصطناعي** مع السعرات والبروتين والكربوهيدرات والدهون والافتراضات، خطة أسبوعية، سجل وزن وجلسات، مفضلة للتمارين، ونسخ احتياطي JSON.
- تصميم RTL ومتجاوب مع الهاتف، وPWA قابلة للتثبيت من المتصفح مع تحسين قائمة الهاتف والتفاعل بلوحة المفاتيح وحالة النوافذ المنبثقة والعمل دون اتصال بعد فتح الصفحات أول مرة.
- نقطة ربط آمنة مع OpenAI Responses API من الخادم؛ المفتاح لا يوضع في ملفات المتصفح.

## نشر الموقع على GitHub Pages (المستودع tamreenak)
1. فك ضغط ملف ZIP على جهازك.
2. ادخل إلى مستودع `tamreenak` في GitHub، ثم **Add file → Upload files**.
3. ارفع **محتويات المجلد** مباشرة إلى جذر المستودع: يجب أن يظهر `index.html` بجانب مجلد `assets`، وليس داخل مجلد فرعي اسمه `tamreenak-site`.
4. اضغط **Commit changes** وانتظر اكتمال النشر.
5. من **Settings → Pages** تأكد أن النشر من الفرع `main` ومجلد `/(root)`، ثم افتح `https://mutazzp.github.io/tamreenak/`.
6. إذا بقيت نسخة قديمة، حدّث الصفحة تحديثًا قويًا أو امسح بيانات الموقع؛ قد يحتفظ Service Worker بالنسخة السابقة لفترة.

**مهم:** GitHub Pages يستضيف ملفات ثابتة فقط. صفحات التمارين والملف والخطة والسعرات والتقدم والحفظ المحلي تعمل دون خادم. مدرب الذكاء الاصطناعي وتقدير الوجبة الذكي يحتاجان وظيفة خادم مثل Netlify Functions مع `OPENAI_API_KEY`، ولن يعمل الاتصال الخلفي على GitHub Pages وحده. لا تضع مفتاح API في ملفات JavaScript أو مستودع عام.

## تشغيل الموقع على الكمبيوتر
1. ثبّت Node.js 20 أو أحدث.
2. افتح مجلد المشروع في Terminal.
3. نفّذ `npm start`.
4. افتح `http://localhost:4173`.

في ويندوز يمكن تشغيل `start-windows.bat` بعد تثبيت Node.js.

## تفعيل ChatGPT وتقدير الوجبات الذكي
- مدرب الذكاء الاصطناعي وتقدير الوجبات يعتمدان على OpenAI API. أنشئ مفتاح API من منصة OpenAI API؛ اشتراك ChatGPT وحده لا يعني أن استخدام API مجاني.
- للتشغيل المحلي، عيّن متغيري البيئة `OPENAI_API_KEY` و(اختياريًا) `OPENAI_MODEL` قبل `npm start`.
- على Netlify: الأفضل ربط المشروع بمستودع GitHub أو نشره عبر Netlify CLI حتى يتم اكتشاف `netlify/functions/coach.mjs`. بعد النشر افتح Site configuration → Environment variables، وأضف `OPENAI_API_KEY` بقيمة المفتاح واجعل نطاقه Functions، ثم أعد النشر. لا تحفظ المفتاح في GitHub ولا ضمن ملفات `assets`.
- النموذج الافتراضي `gpt-4.1-mini` ويمكن تغييره بمتغير `OPENAI_MODEL` إذا كان متاحًا لحسابك.

## تثبيته على الهاتف
- ارفع المشروع إلى استضافة HTTPS مثل Netlify.
- **Android:** افتح الموقع في Chrome → قائمة المتصفح → «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- **iPhone:** افتح الرابط في Safari → مشاركة → «إضافة إلى الشاشة الرئيسية».
- هذه نسخة PWA تثبّت من المتصفح؛ ليست APK مستقلة أو تطبيقًا منشورًا في Google Play / App Store.

## الخصوصية والبيانات
الملف والخطة والوجبات وسجل الوزن والتمارين تحفظ محليًا في `localStorage` على الجهاز. من الإعدادات يمكنك تصدير نسخة JSON أو استيرادها. حذف بيانات المتصفح قد يمحوها. عند استخدام مدرب الذكاء الاصطناعي، الرسائل المرسلة وبيانات ملف بسيطة (العمر/الهدف/المستوى/مكان التدريب) تمر إلى الخادم ومزود API للرد.

## ملاحظة طبية مهمة بشأن تقوس الظهر
صفحة وضعية الظهر تعرض تمارين عامة للحركة والثبات وتقوية عضلات الدعم. التقوس قد يكون حدبًا أو زيادة تقوس قطني أو جنفًا، والخطة تختلف حسب السبب والنوع. لا تضمن هذه التمارين تصحيح انحناء عظمي؛ عند التقوس الواضح أو المتزايد أو الألم، اطلب تقييم طبيب أو أخصائي علاج طبيعي. أوقف أي تمرين يسبب ألمًا أو تنميلًا.

## الاختبار
تحقق من ملفات JavaScript وخادم Node واكتمال الصفحات ومكتبة التمارين عبر `npm run check`. اختبر الصفحات على استضافة HTTPS. بعد تحديث النسخة المنشورة حدّث الصفحة بقوة أو امسح بيانات الموقع إذا ظهرت نسخة مخزّنة.
